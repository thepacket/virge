# Contributing

**This project does not accept pull requests.**

VIRGE is developed as a personal project with a deliberately narrow scope.
Pull requests opened against this repository will be closed unread, and an
automated workflow closes them on arrival. Please do not spend your time
preparing one.

## What is welcome

**Bug reports**, particularly ones about incorrect biology. If a digest,
fragment size, methylation call or enzyme definition disagrees with a published
map or your bench results, please open an issue with the DNA (accession or
sequence), the enzymes, what VIRGE produced, and what you expected. Those
reports are valuable and will be acted on.

## Forking

The MIT licence permits forking, modifying and redistributing this code,
including for commercial use. If you want the project to go in a different
direction, fork it — that is what the licence is for. The only requirement is
that the copyright notice and licence text travel with the copy.

GenBank. Neither is covered by this project's MIT licence; if you redistribute
